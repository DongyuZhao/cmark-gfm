## Directive option gates

These examples attach the directive extension without enabling its
parser option. The extension syntax remains ordinary Markdown.

```````````````````````````````` example
Use :cite[smith04] here.
.
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE document SYSTEM "CommonMark.dtd">
<document xmlns="http://commonmark.org/xml/1.0">
  <paragraph>
    <text xml:space="preserve">Use :cite[smith04] here.</text>
  </paragraph>
</document>
````````````````````````````````

```````````````````````````````` example
::youtube[Video]{vid=01ab2cd3efg}
.
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE document SYSTEM "CommonMark.dtd">
<document xmlns="http://commonmark.org/xml/1.0">
  <paragraph>
    <text xml:space="preserve">::youtube[Video]{vid=01ab2cd3efg}</text>
  </paragraph>
</document>
````````````````````````````````
