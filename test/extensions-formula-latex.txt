## LaTeX formula compatibility

These examples define the opt-in LaTeX delimiter surface supported by
the `formula` extension when `--latex-formula-delimiters` is enabled, in addition to
GitHub's documented `$` and `$$` forms.

```````````````````````````````` example
Inline \\(x+y\\) end.
.
<p>Inline <span class="formula formula-inline">\(x+y\)</span> end.</p>
````````````````````````````````

Single-backslash LaTeX-looking delimiters are ordinary Markdown escapes, not
formula delimiters.

```````````````````````````````` example
Inline \(x+y\) end.
.
<p>Inline (x+y) end.</p>
````````````````````````````````

```````````````````````````````` example
Display \\[x+y\\] end.
.
<p>Display <span class="formula formula-display">\[x+y\]</span> end.</p>
````````````````````````````````

```````````````````````````````` example
Display \[x+y\] end.
.
<p>Display [x+y] end.</p>
````````````````````````````````

```````````````````````````````` example
\\[x+y\\]
.
<div class="formula formula-display">\[x+y\]</div>
````````````````````````````````

```````````````````````````````` example
\\[
x+y
\\]
.
<div class="formula formula-display">\[x+y\]</div>
````````````````````````````````

Display formula blocks bind before Markdown block syntax inside the body.

```````````````````````````````` example
\\[
\\nabla \\times \\boldsymbol{E}
=
-\\frac{\\partial \\boldsymbol{B}}{\\partial t}
\\]
.
<div class="formula formula-display">\[\\nabla \\times \\boldsymbol{E}
=
-\\frac{\\partial \\boldsymbol{B}}{\\partial t}\]</div>
````````````````````````````````

```````````````````````````````` example
Text $$x+y$$ end.
.
<p>Text <span class="formula formula-display">\[x+y\]</span> end.</p>
````````````````````````````````

Dollar display formula blocks bind before Markdown block syntax inside the body.

```````````````````````````````` example
$$
\\nabla \\times \\boldsymbol{E}
=
-\\frac{\\partial \\boldsymbol{B}}{\\partial t}
$$
.
<div class="formula formula-display">\[\\nabla \\times \\boldsymbol{E}
=
-\\frac{\\partial \\boldsymbol{B}}{\\partial t}\]</div>
````````````````````````````````

Escaped backslash closers are body text, not delimiters.

```````````````````````````````` example
Text \\(a \) b\\) end.
.
<p>Text <span class="formula formula-inline">\(a ) b\)</span> end.</p>
````````````````````````````````

When a body contains the matching backslash delimiter, render with dollar
delimiters so LaTeX does not close early.

```````````````````````````````` example
Text $a\\)b$ end.
.
<p>Text <span class="formula formula-inline">$a\\)b$</span> end.</p>
````````````````````````````````

```````````````````````````````` example
Text $$a\\]b$$ end.
.
<p>Text <span class="formula formula-display">$$a\\]b$$</span> end.</p>
````````````````````````````````
