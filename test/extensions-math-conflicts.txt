## Math syntax conflict behavior

These examples define precedence where GitHub math compatibility and MathJax
compatibility touch existing Markdown syntax or each other.

Code spans bind before math delimiters inside the span.

```````````````````````````````` example
Code `$x$` and math $x$.
.
<p>Code <code>$x$</code> and math <span class="math math-inline">\(x\)</span>.</p>
````````````````````````````````

The GitHub `$`...`$` math form binds as math, not as a code span.

```````````````````````````````` example
Math $`x`$ not code.
.
<p>Math <span class="math math-inline">\(x\)</span> not code.</p>
````````````````````````````````

A same-line display close followed by non-whitespace trailing text is inline
display math inside a paragraph, not a math block.

```````````````````````````````` example
$$x$$ trailing
.
<p><span class="math math-display">\[x\]</span> trailing</p>
````````````````````````````````

```````````````````````````````` example
\\[x\\] trailing
.
<p><span class="math math-display">\[x\]</span> trailing</p>
````````````````````````````````

Indented code takes precedence over math block openers.

```````````````````````````````` example
    $$x$$
.
<pre><code>$$x$$
</code></pre>
````````````````````````````````

Non-`math` fenced code remains ordinary code.

```````````````````````````````` example
```js
$x$
```
.
<pre><code class="language-js">$x$
</code></pre>
````````````````````````````````

Code spans also bind before MathJax backslash delimiters.

```````````````````````````````` example
Code `\\(x\\)` and math \\(x\\).
.
<p>Code <code>\\(x\\)</code> and math <span class="math math-inline">\(x\)</span>.</p>
````````````````````````````````
